# Prosper Nkala Inc. website

This folder contains the complete Prosper Nkala Inc. website and is ready to upload to GitHub Pages.

## Fastest launch method

1. Sign in to GitHub and create a new repository named `prosper-nkala-inc`.
2. Extract the supplied ZIP file on your computer.
3. Upload **all** extracted files and folders to the new repository. Include the hidden `.github` folder.
4. Open the repository's **Settings** tab.
5. Select **Pages** under **Code and automation**.
6. Under **Build and deployment**, set **Source** to **GitHub Actions**.
7. Open the repository's **Actions** tab. The workflow named **Deploy Prosper Nkala Inc. website** will publish the site automatically.
8. When the workflow shows a green tick, open the website address displayed under **Settings > Pages**.

No website builder, database, paid plugin or server is required.

## Connect prospernkalainc.co.za after the GitHub address works

1. In **GitHub > Settings > Pages**, enter `prospernkalainc.co.za` under **Custom domain** and save.
2. GitHub will display the DNS records required for the domain.
3. In the Axxess DNS management screen, preserve a record of the existing DNS settings before changing anything.
4. Add only the website DNS records shown by GitHub. The `www` record will normally point to the GitHub Pages host name linked to your GitHub username.
5. Wait for GitHub's DNS check to pass, then select **Enforce HTTPS**.

**Important:** do not change email-related MX, SPF, DKIM or DMARC records when connecting the website. Those records control email delivery and are separate from the website.
