# Prosper Nkala Inc. Official Website

This is the official website of Prosper Nkala Inc., incorporated attorneys based in Midrand, South Africa.

## Quick Start

The website is automatically published via GitHub Pages when changes are pushed to the main branch.

## Website Structure

- `index.html` — Homepage with full firm information
- `privacy.html` — POPIA-aligned privacy notice  
- `legal-notice.html` — Legal disclaimer and website terms
- `styles.css` — Responsive design and styling
- `script.js` — Client-side functionality (navigation, scroll tracking, current year)
- `assets/` — Logos, icons and social media images
- `.github/workflows/deploy-pages.yml` — Automatic GitHub Pages publishing workflow

## Publishing to a Custom Domain

1. In **GitHub Settings > Pages**, enter `prospernkalainc.co.za` under **Custom domain**
2. GitHub will show the DNS records needed
3. Update your domain's DNS settings accordingly
4. GitHub's DNS check will pass automatically
5. Enable HTTPS enforcement

## Before Launch

Please confirm the following regulatory information is accurate and complete:
- Legal Practice Council registration particulars
- Company registration and VAT details
- Fidelity Fund Certificate status
- Privacy contact/Information Officer details
- Attorney biography and credentials
